# 🎣 AWS Fishing — ตกปลา · ตอบคำถาม · เอาตัวรอด

เกมตกปลา Pixel Art 2D บนเว็บ (เล่นได้ทั้งคอมและมือถือ) ที่สอดแทรกความรู้ **AWS Cloud**
ได้แรงบันดาลใจด้านรูปแบบการเล่นจากเกม Jam *LD59 Hooked* — ตกปลา จัดของลงกระเป๋าแบบ Tetris เอาตัวรอดกลางทะเล แล้วกลับท่าเรือไปขายและอัปเกรด
งานภาพ เสียง และโค้ดทั้งหมดสร้างขึ้นใหม่ด้วยโค้ด (procedural pixel art + WebAudio) ไม่มีไฟล์ asset ภายนอก

## วิธีเล่น
| การกระทำ | คอม | มือถือ |
|---|---|---|
| เหวี่ยงเบ็ด | กดค้างที่ทะเล (หรือ Space) แล้วปล่อย | แตะค้างแล้วปล่อย |
| ตวัดเบ็ด | คลิกเมื่อทุ่นจมและมี **!** | แตะ |
| ตอบคำถาม | คลิก / ปุ่ม 1-4, A-D, T/F | แตะ |
| ลากปลาใส่กระเป๋า | ลากเมาส์ | ลากนิ้ว (แตะปลา = จัดวางอัตโนมัติ) |
| หมุนปลา | คลิกขวา / R / คลิกปลาที่เลือกอยู่ | แตะนิ้วที่สองระหว่างลาก / แตะปลาที่เลือกอยู่ |

### ระบบหลัก
- **ระดับปลา ★1–★5** — ★1 ถาม ถูก/ผิด · ★2 ผสม · ★3+ เป็น 4 ตัวเลือกและต้องตอบถูกหลายข้อ
- **เกจแรงดิ้นหนี** ลดลงเรื่อยๆ ตอบผิดจะลดฮวบ ถ้าหมดปลาหลุด ปลายิ่งหายาก เกจยิ่งลดไว
- **HP ลดตลอดเวลากลางทะเล** + อีเวนต์ (พายุฝน, หมอกเยือกแข็ง, ฉลาม, แมงกะพรุนไฟ, หนวดปีศาจ) — ใช้ไอเท็มรับมือ ถ้าหมดสติ ปลาในกระเป๋าหายหมด
- **5 น่านน้ำ** อ่าวชายฝั่ง → แนวปะการัง → ทะเลร้าง → ร่องลึกรัตติกาล → มหาสมุทรพายุคลั่ง ยิ่งไกลยิ่งได้ปลาหายาก ราคาดี แต่คำถามยากและอันตรายขึ้น
- **อัปเกรด**: พลังชีวิต, กระเป๋า (เพิ่มช่อง), คันเบ็ด (เกจลดช้าลง), สายเบ็ด (ตอบผิดเสียน้อยลง), ตำราปราชญ์ (ลดจำนวนข้อที่ต้องตอบ), เรือ (ปลดล็อกน่านน้ำ)
- **สมุดบันทึกปลา** 19 สายพันธุ์ · บันทึกเกมอัตโนมัติใน localStorage

## รันบนเครื่อง
ไม่ต้อง build — เป็น HTML/JS ล้วน
```bash
python -m http.server 8765
```
แล้วเปิด http://localhost:8765 (หรือเปิด `index.html` ตรงๆ ก็ได้)

### เผยแพร่ด้วย GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → `main` / root

## แก้ไขคำถาม
คำถามทั้งหมดอยู่ใน [`js/questions.js`](js/questions.js) — ตัวเลือกแรกคือคำตอบที่ถูก (เกมจะสลับให้เอง)
```js
{ lv:1, tf:true, q:'Amazon S3 เป็น Object Storage', e:'คำอธิบาย' }                 // ถูก/ผิด
{ lv:2, q:'คำถาม?', c:['คำตอบถูก','ผิด','ผิด','ผิด'], e:'คำอธิบาย' }                 // 4 ตัวเลือก
```

## โครงสร้าง
```
index.html          หน้าเกม + UI
css/style.css       สไตล์ UI แบบ pixel
js/questions.js     คลังคำถาม AWS (ไทย)
js/data.js          ปลา / น่านน้ำ / อัปเกรด / ไอเท็ม / อีเวนต์
js/gfx.js           pixel-art toolkit + เครื่องสร้างสไปรต์ปลา
js/scene.js         ท้องฟ้า ทะเล ท่าเรือ เรือ สภาพอากาศ อีเวนต์
js/inventory.js     กระเป๋าแบบ grid (polyomino)
js/audio.js         เสียงเอฟเฟกต์และดนตรีสังเคราะห์
js/game.js          ลูปเกม ตกปลา ควิซ ร้านค้า บันทึกเกม
```
